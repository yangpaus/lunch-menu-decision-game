# 점심 메뉴 결정 게임

오늘 점심 뭐 먹을지 모르겠다면, 게임으로 결정하세요.

메뉴 이름이 공이 되어 화면을 날아다닙니다. 어느 쪽 골대로 빠져나가느냐에 따라 오늘의 점심 메뉴가 정해집니다.

---

## 실행 방법

별도 설치 없이 `index.html` 파일을 브라우저에서 열면 바로 실행됩니다.

단, `items.json`을 불러오기 때문에 로컬 서버가 필요합니다.

**VS Code를 사용하는 경우:**
Live Server 익스텐션을 설치하고 `index.html`에서 우클릭 → `Open with Live Server`

**터미널을 사용하는 경우:**
```bash
npx serve .
```

---

## 조작법

| 입력 | 동작 |
|------|------|
| 마우스 상하 이동 | 왼쪽 패들 조작 |
| 클릭 | 결과 화면에서 게임 재시작 |

오른쪽 패들은 AI가 자동으로 조작합니다.

## 동작 원리

### 글자 잔상 생성

메뉴 텍스트는 한 덩어리가 아니라, 글자 하나하나가 서로 다른 위치에 그려지면서 꼬리처럼 이어지는 잔상 효과를 만들어냅니다.

매 프레임마다 공의 현재 위치를 `history` 배열에 저장합니다. 글자를 그릴 때는 가장 최근 위치부터 `gapFrames` 간격으로 이전 위치를 꺼내어 각 글자를 배치합니다.

```
현재 위치 → 첫 번째 글자
gapFrames 이전 위치 → 두 번째 글자
gapFrames × 2 이전 위치 → 세 번째 글자
...
```

`gapFrames`는 속도에 따라 동적으로 계산됩니다. 공이 빠를수록 글자 간격이 넓어지고, 느릴수록 글자가 촘촘하게 모입니다.

```javascript
gapFrames() {
  const speed = this.vel.mag();
  const step  = textSize();
  return max(1, round(step / speed));
}
```

### 볼의 움직임

공은 `pos`(위치)와 `vel`(속도 벡터)로 움직입니다.

**상하 벽 반사**
공이 화면 위아래 경계에 닿으면 y 속도의 부호를 반전합니다. 반사할 때마다 메뉴 텍스트가 새 항목으로 바뀌고 색상이 변합니다.

**패들 충돌**
패들을 7개 구간으로 나누어, 어느 위치에 맞느냐에 따라 y 속도가 달라집니다. 패들 중앙에 맞으면 수평에 가깝게, 끝부분에 맞을수록 각도가 커집니다.

```
패들 위쪽 끝 → 위로 날카롭게 꺾임
패들 중앙    → 수평으로 반사
패들 아래쪽 끝 → 아래로 날카롭게 꺾임
```

**속도 증가**
랠리 횟수가 쌓일수록 게임이 빨라집니다.

| 랠리 횟수 | 변화 |
|-----------|------|
| 4회 | x 속도 1.25배, 최대 y 속도 1.15배 |
| 12회 | x 속도 1.25배, 최대 y 속도 1.15배 (한 번 더) |

### 골 판정

공의 x 좌표가 화면 왼쪽 경계 밖으로 나가면 **AI 승리**, 오른쪽 경계 밖으로 나가면 **플레이어 승리**입니다. 어느 쪽이 이기든 그 순간 공이 표시하던 메뉴가 오늘의 점심으로 결정됩니다.

## 메뉴 추가·수정 방법

`items.json` 파일을 편집하면 됩니다.

```json
[
  "순대국밥",
  "참치김치찌개",
  "원하는 메뉴 추가",
  ...
]
```

항목을 추가하거나 삭제한 뒤 저장하면 다음 실행부터 반영됩니다.
